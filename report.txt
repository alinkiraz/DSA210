This project analyzes whether the origin of a movie’s lead actor has a relationship with movie budget, popularity, and audience ratings. The dataset used in this project comes from the TMDb 5000 Movies and TMDb 5000 Credits datasets. The movies dataset contains information such as budget, revenue, popularity, runtime, vote count, and vote average, while the credits dataset contains cast information for each movie.

First, the two datasets were merged together using the movie title. Then, the first actor listed in the cast column was selected as the lead actor because TMDb orders actors by cast billing. After identifying the lead actors, the TMDb API was used to collect additional information about each actor, especially their place of birth. To reduce unnecessary API calls, only unique actors were queried.

The actors were then classified into two groups: Western and Non-Western. The Western group included most European countries, the United States, Canada, Australia, New Zealand, and Russia. Turkey was intentionally excluded from the Western category. Movies with missing actor origin information were removed before analysis.

Several exploratory data analysis methods were used to better understand the dataset. Histograms, boxplots, violin plots, scatter plots, and a correlation heatmap were created. These visualizations helped compare the distributions of budgets, popularity scores, and ratings between the two actor origin groups. The graphs showed that movies with Western lead actors generally had higher budgets and popularity values.

Before hypothesis testing, normality tests were applied to both groups. Since the variables did not follow a normal distribution, the Mann-Whitney U test was selected instead of the independent samples t-test. Three main hypothesis tests were performed. The first test showed that movies with Western lead actors have significantly higher budgets. The second test showed that movies with Non-Western lead actors have slightly higher average ratings. The third test showed that movies with Western lead actors have significantly higher popularity values.

In the machine learning section, two regression models were used to predict movie ratings. The first model was Linear Regression, which used budget, popularity, and actor origin as features. However, the model produced a very low R² score, meaning that the selected variables could not explain movie ratings well using a simple linear relationship. After this, a Decision Tree Regression model was tested with additional features such as runtime, vote count, and log-transformed budget values. This model performed much better and achieved a higher R² score.

Overall, the project shows that there are meaningful differences between movies with Western and Non-Western lead actors in terms of budget, popularity, and ratings. The project also demonstrates how data cleaning, API enrichment, visualization, statistical testing, and machine learning methods can be combined in a complete data science workflow.
